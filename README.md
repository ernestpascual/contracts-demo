# Contracts Demo

A demonstration repository for smart contract development, testing, and deployment. 

## 📖 Overview
This project serves as a sandbox for building and interacting with decentralized protocols. It includes the source code for the smart contracts, comprehensive test suites, and scripts for local and testnet deployments.

## 🛠 Tech Stack
* **Smart Contracts:** Solidity
* **Development Environment:** [Hardhat / Foundry]
* **Testing & Scripting:** TypeScript / Node.js
* **Frontend Integration:** Structured for easy ABI export to Next.js/React client applications.

## 🚀 Getting Started

### Prerequisites
* Node.js (v18+)
* [Yarn / npm / pnpm]
* [Foundry / forge ]
